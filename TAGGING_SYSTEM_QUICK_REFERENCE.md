# HeyCloset Tagging System - Quick Reference\n\n## 🎯 Quick Start (5 Minutes)\n\n### 1. Run Migrations\n```bash\npsql -U postgres -d heycloset < data/migration_001_tagging_system.sql\npsql -U postgres -d heycloset < data/migration_002_populate_tags.sql\n```\n\n### 2. Replace ItemModal\n```tsx\nimport { ItemModalWithTags } from '@/components/ItemModalWithTags';\n\n<ItemModalWithTags\n  closetId={closetId}\n  onClose={() => setShowModal(false)}\n  onSave={handleItemSaved}\n/>\n```\n\n### 3. Add Filtering\n```tsx\nimport { useTagFilter } from '@/hooks/useTagManagement';\nimport { filterItemsByTags } from '@/lib/tagFiltering';\n\nconst filter = useTagFilter();\nconst filtered = filterItemsByTags(items, {\n  categories: filter.categoryFilter ? [filter.categoryFilter] : undefined,\n});\n```\n\nDone! ✅\n\n---\n\n## 📚 Common Usage Patterns\n\n### Fetch Tag Metadata\n```tsx\nconst { seasons, styles, occasions, loading } = useTagMetadata();\n\nif (loading) return <div>Loading...</div>;\n\nconst seasonOptions = seasons.map(s => ({\n  id: s.id.toString(),\n  label: s.season_name\n}));\n```\n\n### Manage Item Tags\n```tsx\nconst { itemTags, customTags, addTag, removeTag, addCustomTag } = useItemTags(itemId);\n\n// Add season tag\nawait addTag({\n  dk_itemid: itemId,\n  dk_seasonid: 1,\n  tag_source: 'user'\n});\n\n// Add custom tag\nawait addCustomTag('vintage-inspired', 'user_defined');\n```\n\n### Filter Items\n```tsx\n// By category\nconst tops = filterItemsByTags(items, {\n  categories: ['tops']\n});\n\n// By color\nconst blue = filterItemsByTags(items, {\n  primaryColors: ['blue']\n});\n\n// By multiple filters\nconst winterCoats = filterItemsByTags(items, {\n  categories: ['outerwear'],\n  seasonIds: [4],  // winter\n  warmthLevels: ['very-warm']\n});\n```\n\n### Sort & Search\n```tsx\nconst sorted = sortItems(items, 'newest');\nconst results = searchItems(items, 'blue shirt');\n```\n\n### Get Statistics\n```tsx\nconst stats = getTagStatistics(items);\n// Returns: categories, colors, warmthLevels, brands, avgRating, avgPrice, totalItems\n```\n\n---\n\n## 🧩 Component /occasion\n\n# POST create tag\nPOST /itemtag\n  { dk_itemid, dk_seasonid, dk_styleid, dk_occasionid, tag_source }\n\n# POST create custom tag\nPOST /customtag\n  { dk_itemid, tag_name, tag_category }\n\n# PUT update item with tag fields\nPUT /item/:id\n  { category, subcategory, primary_color, secondary_color, brand, warmth_level, fit }\n\n# DELETE tag\nDELETE /itemtag/:id\nDELETE /customtag/:id\n```\n\n---\n\n## ⚡ Performance Tips\n\n1. **Cache metadata** - useTagMetadata() caches results\n2. **Use views** - Query `item_with_tags` for complex queries\n3. **Index fields** - All
